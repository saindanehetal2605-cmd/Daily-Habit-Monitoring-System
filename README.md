# Daily-Habit-Monitoring-System
A Python Tkinter and MySQL-based system to manage daily habits, track progress, and record completion status.
Daily Habit Monitoring System

Project Description

The Daily Habit Monitoring System is a desktop application developed using Python, Tkinter, and MySQL. It helps users manage daily habits, track progress, and record completion status.

Features

- User Registration and Login
- Add, View, Search, Update, and Delete Habits
- Set Habit Categories and Daily Targets
- Mark Habits as Completed or Not Completed
- View Daily Records and Progress
- Store Data in MySQL Database

Technologies Used

- Python
- Tkinter
- MySQL
- mysql-connector-python

Application Modules

1. Registration Module
2. Login Module
3. Dashboard Module
4. Add Habit Module
5. View Habits Module
6. Search Habit Module
7. Update Habit Module
8. Delete Habit Module
9. Daily Status Module
10. Daily Records Module
11. Logout Module

How to Run

1. Install Python and MySQL.
2. Install the required library using "pip install -r requirements.txt".
3. Configure your MySQL password in the Python program.
4. Start the MySQL server.
5. Run "python daily_habit_monitoring.py".
6. Register a new account and log in.

Login Details

There is no default login account. Create your own account using the registration option, then log in with your registered username and password.

Database

The application uses MySQL to store user accounts, habits, and daily habit records.

Project Purpose

The main purpose of this project is to help users develop good habits and monitor their daily progress efficiently.
